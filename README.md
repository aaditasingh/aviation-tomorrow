# Aviation Tomorrow — starter website

A responsive static website for GitHub Pages.

## Publish it on GitHub Pages
1. Create a **public** repository named `aviation-tomorrow`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the published site link to appear in Settings → Pages.

## Custom domain later
When you own `aviationtomorrow.org`, add it in Settings → Pages → Custom domain, then configure DNS with your domain registrar. Follow GitHub's current guide:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

## Before launch
- Replace placeholder copy with your verified existing website content.
- Add your own contact details only if you want them public.
- Check all research claims and link reliable sources.
- Do not publish private personal information or secrets.
